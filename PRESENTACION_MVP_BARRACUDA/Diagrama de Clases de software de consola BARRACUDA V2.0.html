Diagrama de Clases de software de consola BARRACUDA V2.0

Diseño, Desarrollo e Implementación de un Ecosistema de Software Concurrente para la Integración Multi-Protocolo, Procesamiento Lógico en Tiempo Real y Visualización Táctica de Datos en Sistemas Navales de Control de Armas

Información General de Comunicación

El sistema BARRACUDA V2.0 opera como un Nodo de Integración (Gateway) que orquesta tres dominios de red distintos para garantizar la sincronización operativa entre el hardware periférico y el núcleo de Gabinete de interfas (IC).

  • Dominio UDP (Recepción Periférica): Comunicación no orientada a conexión utilizada para la ingesta de datos de alta frecuencia desde Joysticks, Teclados y el Sistema de Gestión de Combate (CMS).
  • Dominio TCP (Sincronización Crítica): Enlace punto a punto persistente y fiable con el Gabinete Interfas IC. Utiliza el puerto 60XX para transmitir tramas binarias de control de 29 bytes con verificación de integridad.
  • Dominio WebSocket (Visualización Realtime): Canal Full-Duplex para la actualización reactiva de la interfaz de usuario en el navegador del operador.

    class Servidor {
        +wss: WebSocketServer
        +sensorsService: ServicioSensores
        +tcpService: ServicioTCP
        +binaryProtocol: ServicioProtocoloBinario
        +feedbackService: ServicioFeedback
        +stationManager: GestorEstaciones
        +iniciar()
        +manejarWS()
    }

    class ServicioSensores {
        +sockets: Map
        +udpService: ServicioUDP
        +handleMessage(msg)
        +emit('data')
    }

    class ServicioUDP {
        +socket: dgram
        +bind(port)
        +send(msg, host, port)
    }

    class ServicioProtocoloBinario {
        +consoleId: String
        +state: Object
        +generateFrame(options)
        +parseFrame(data)
        +updateField(field, value)
        +calculateChecksum(buffer)
        +interpret(buffer)
    }

    class ServicioTCP {
        +client: net.Socket
        +connected: Boolean
        +connect(stationId, host, port)
        +send(buffer)
        +disconnect()
    }

    class GestorEstaciones {
        +activeStations: Map
        +assignStation(client, id)
        +getStationConfig(id)
        +validateHandshake()
    }

    class ServicioCMS {
        +parseStatus(buffer)
        +processCommand(cmd)
        +syncPanel()
    }

    class ServicioFeedback {
        +startHeartbeat()
        +sendFeedback(data)
        +stop()
    }

    class ServicioPanel {
        +parseKeyboard(str)
        +emit('panel_update')
    }

    class ServicioNMEA {
        +parseSentence(line)
        +extractGPSData()
    }

    class ServicioEventos {
        +log(type, module, msg)
        +persistence: Array
    }

    class ServicioConfig {
        +CONSOLE_ID: String
        +IC_HOST: String
        +PORTS: Object
        +load()
    }
